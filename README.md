# Insurance Claims Management System

A Python-based application for registering, viewing, and updating insurance claims using an SQLite database.

## Features

- Register new insurance claims
- View all registered claims
- Update claim statuses
- Validate claim amounts and required fields
- Store claim records in SQLite
- Automated database tests

## Technologies Used

- Python 3.13
- SQLite
- unittest

## Requirements

- Python 3.10 or later
- No external Python packages required

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the application:

   `python main.py`

## Run Tests

Run the automated tests with:

`python -m unittest test -v`

## Learning Objectives

This project demonstrates Python functions, exception handling, SQL operations, database management, input validation, and automated testing.

## Project Status

Developed as a learning project. Further improvements may include customer authentication, policy management, and a web interface.
